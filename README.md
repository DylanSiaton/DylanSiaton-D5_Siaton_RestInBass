# REST IN BASS · D-5 final package

**Student:** Dylan Siaton · Cross Media Design I · Erasmushogeschool Brussel
**Festival:** REST IN BASS, an inclusive music festival for people with a hearing disability: *music is more than what you hear.*
**Tagline:** turn up the feeling
**Date and venue (concept):** Saturday 26 June 2027 · Tour & Taxis, Brussels
**Core touchpoint:** an anaglyph 3D invitation sent by post, with collectible red/cyan 3D glasses. The glasses make the logo pop off the card and reveal a hidden message; the QR code opens the teaser.
